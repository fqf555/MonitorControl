Standard volume keys now use MonitorControl's smooth adjustment and HUD for MacBook speakers, headphones, and other native macOS audio outputs.

## Changes

- Hold a standard volume key to adjust continuously; release it to stop. Mute/unmute uses the same HUD. Turning smooth adjustment off retains stepped changes.
- Preserve the original audio-target selection: native outputs use the selected macOS audio device; outputs without native volume control use monitor DDC. Explicit display-name matching still takes precedence.
- Keep custom volume shortcuts DDC-only, and clarify the Keyboard settings description.
- Add regression checks for native/DDC routing, fine and stepped adjustment, release, volume limits, mute restoration, and write failures.

## Install or update

**Apple Silicon (arm64), macOS 12 or newer.** Signed with Developer ID and notarized by Apple. The glass HUD is available on macOS 26 and newer.

If you already use this fork, choose **Check for updates…** in MonitorControl. Otherwise, download `MonitorControl-4.5.2-arm64.zip`, unzip it, quit MonitorControl, and move the app to Applications.

Version **4.5.2**, build **7163** (previous release: 4.5.1, build 7162). Enable MonitorControl in **System Settings → Privacy & Security → Accessibility** for standard brightness and volume keys to work, then quit and reopen the app if you have just granted permission.

If held-key brightness adjustment feels slow, disable **Use fine OSD scale for brightness and contrast** in Keyboard settings. Fine mode intentionally runs at one quarter of the normal speed; no brightness timing change is included in this release.
