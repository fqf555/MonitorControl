Improved readability of the volume, brightness, and contrast HUD in dark mode.

## Changes

- The filled adjustment bar is now white in dark mode, with a dimmer track behind it.
- Bar colors update when the HUD inherits its window appearance or the appearance changes.
- Added shortcut-dispatch diagnostics and regression checks.

## Install or update

**Apple Silicon (arm64), macOS 12 or newer.** Signed with Developer ID and notarized by Apple.

If you already have this fork's 4.5.0 release, choose **Check for updates…** in MonitorControl. Otherwise, download `MonitorControl-4.5.1-arm64.zip`, unzip it, quit MonitorControl, and move the app to Applications.

Version **4.5.1**, build **7162** (previous release: 4.5.0, build 7161). This release preserves the original app's DDC-only volume shortcut behavior; MacBook speakers use the normal macOS volume controls.
