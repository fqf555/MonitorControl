First signed and notarized release of Qifeng's MonitorControl fork.

## Download and install

**Apple Silicon (arm64) only, macOS 12 or newer.** Download `MonitorControl-4.5.0-arm64.zip`, unzip it, quit MonitorControl, and move the app to Applications. It is signed by Qifeng Fu and notarized by Apple.

When switching from the upstream app, install this release manually once. If keyboard controls remain blocked despite an enabled Accessibility entry, remove the old MonitorControl entry in System Settings → Privacy & Security → Accessibility (Device Control and Data Access on newer macOS), then add and enable the newly installed app.

## Changes

- Modern app icon avoids the legacy gray surround on newer macOS.
- Compact top-right glass HUD for volume, mute, brightness, and contrast on macOS 26 and newer, showing MonitorControl's own values.
- Smooth adjustment now supports elapsed-time, press-and-hold volume, brightness, and contrast control with media keys and custom shortcuts. Release stops adjustment; fine control slows it down. Monitor hardware still limits physical precision.
- In-app updates now come from this repository's GitHub Releases and are verified with this fork's Sparkle signing key.

Build 7161. Future releases can be installed using **Check for updates…** in MonitorControl. GitHub Actions remains disabled.
