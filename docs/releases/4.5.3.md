Fix brightness-state handling and separate menu icons from their slider tracks.

## Changes

- Preserve the last known brightness when native brightness reads fail, instead of treating an error as zero and propagating it to synchronized displays.
- Stop smooth adjustment when a brightness write fails, and start subsequent animations from the latest native brightness value.
- Prevent repeated mirror-shortcut events from repeatedly toggling display mirroring, and ignore the shortcut during sleep or display reconfiguration.
- Move brightness, volume, and contrast icons beside their slider tracks, align percentage labels, and explicitly redraw sliders after keyboard-driven updates.
- Add regression coverage for brightness failures, animation state, mirror-shortcut handling, and menu slider layout and updates.

The menu overlap fix was visually confirmed by the owner on the installed build. The separate report of stale sliders on another computer has not yet been reproduced; the redraw change is not a confirmed resolution of that report.

## Install or update

**Apple Silicon (arm64), macOS 12 or newer.** Signed with Developer ID and notarized by Apple.

Existing users of this fork can choose **Check for updates…** in MonitorControl. For a manual install, download `MonitorControl-4.5.3-arm64.zip`, unzip it, quit MonitorControl, and move the app to Applications.

Version **4.5.3**, build **7164** (previous release: 4.5.2, build 7163).
