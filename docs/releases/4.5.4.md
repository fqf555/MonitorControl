Use MonitorControl’s brightness adjustment and HUD when only the built-in display is connected.

## Changes

- Keep brightness media keys handled by MonitorControl on built-in-only setups, including smooth adjustment and the custom HUD on macOS 26 or newer.
- Temporarily return brightness keys to macOS during sleep or display reconfiguration, when MonitorControl’s display handlers are unavailable.
- Continue to respect the configured brightness keyboard shortcuts.

## Install or update

**Apple Silicon (arm64), macOS 12 or newer.** Signed with Developer ID and notarized by Apple.

Choose **Check for updates…** in MonitorControl, or download `MonitorControl-4.5.4-arm64.zip`, unzip it, quit MonitorControl, and move the app to Applications.
